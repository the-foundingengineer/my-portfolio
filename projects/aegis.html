Aegis Protocol

Lets a human grant an AI agent real spending power — capped, revocable, enforced on-chain.

The Problem

As AI agents start paying for things autonomously — API calls, purchases, subscriptions — there's no trust layer stopping an agent from overspending, getting tricked, or acting outside what its owner actually intended.

The Build

A Soroban (Stellar) smart contract stores immutable spending caps, allowlists, and a master kill switch. An x402 payment middleware inspects every outgoing HTTP request; when a 402 Payment Required response comes back, it checks the intent against the on-chain policy before the Aegis backend signs anything. A dashboard lets the owner revoke access instantly.

What This Proves

A working on-chain policy enforcement layer for autonomous agent payments: intent-level authorization, per-transaction/daily/lifetime spending caps, instant revocation, and an immutable audit trail — built for the Stellar AI Hackathon. Not yet a commercial product.
