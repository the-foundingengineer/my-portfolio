The Problem

A brand/web/motion designer had six strong client projects but no portfolio that actually sold them — just files scattered across drives. Without a real case-study treatment, prospective clients couldn't see the thinking behind the work, only the pictures.

The Build

A custom grid-based layout system built from scratch in plain HTML/CSS/JS — fixed grid lines, full-bleed brand imagery, numbered SVG assets per project — so each of the six case studies reads as its own visual story while sharing one design language. Home, about, and work-index pages tie it together. Iteratively refined through real client feedback (social icons, hero layout, spacing) rather than shipped as a first draft.
